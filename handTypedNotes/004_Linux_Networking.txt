| OSI Layer    | Technical Function                              
| ------------ | ------------------------------------------------|
| Application  | User-level services / app protocols             |
| Presentation | Data translation, encryption, compression       |
| Session      | Session establishment, maintenance, termination |
| Transport    | Reliable delivery, segmentation, error checking |-> tcp(slow but transper the full data used in ex;- mail), udp(fast but transfer not full ex; games data)
| Network      | Routing, addressing, packet forwarding          |
| Data Link    | Local delivery, error detection, MAC addressing |->Check the complete data transfer if anything is missing or what b/w "nw n ph"
| Physical     | Physical signal transmission                    |



Networking cmds
1. IP CMDS- ip addr show 
2. ifconfig
3. ping -> website/vm -> just to check or confirm its up and running
4. traceroute google.com -> trace the route that is hop along with time its taken 
5. netstat -tuln -> protocall has been used
6. ss -tuln (alternative to netstat -tuln ) which will gives the protocalls in detials list
7. route -n ->  gives the details of the data packates are travelling.
8. dig google.com -> cmd domain name to ip address
9. nslookup google.com-> alternative to dig cmd as nslookup shows the easy readable format that domains ip adress.
10. sudo iptable -A INPUT -p tcp --dport 22 -j ACCEPT -> accept the data from this 
11. sudo iptable -A INPUT -p tcp --dport 22 -j DROP -> will drop.
